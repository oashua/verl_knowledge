2. 4B 级：单机 8 卡 GRPO（FSDP）

来源：run_qwen3_4b_fsdp.sh。小模型的标准形态——不加 TP，纯 FSDP 全分片。

trainer.nnodes=1  trainer.n_gpus_per_node=8
data.train_batch_size=512          data.max_response_length=1024
actor_rollout_ref.actor.fsdp_config.param_offload=False      # 显存够，不开
actor_rollout_ref.actor.fsdp_config.optimizer_offload=False
actor_rollout_ref.ref.fsdp_config.param_offload=True          # ref 无梯度，白占显存，offload
actor_rollout_ref.rollout.tensor_model_parallel_size=2

要点：小模型瓶颈在推理侧并发，rollout TP=2 出 4 个 replica；训练侧无任何 offload 换速度。

3. 8B 级：单机 8 卡 PPO（FSDP / Megatron）

3.1 FSDP 版（ppo_trainer/run_qwen3_8b_fsdp.sh）——最常被参考的基线

data.train_batch_size=1024        actor_rollout_ref.actor.ppo_mini_batch_size=256
data.max_prompt_length=1024       data.max_response_length=2048
actor_rollout_ref.model.use_remove_padding=True
actor_rollout_ref.model.enable_gradient_checkpointing=True
actor_rollout_ref.actor.use_dynamic_bsz=True
actor_rollout_ref.actor.ppo_max_token_len_per_gpu=24576
actor_rollout_ref.rollout.log_prob_use_dynamic_bsz=True
actor_rollout_ref.rollout.log_prob_max_token_len_per_gpu=24576
actor_rollout_ref.ref.log_prob_use_dynamic_bsz=True
actor_rollout_ref.ref.log_prob_max_token_len_per_gpu=24576
actor_rollout_ref.actor.optim.lr=1e-6          critic.optim.lr=1e-5
actor_rollout_ref.rollout.tensor_model_parallel_size=2
actor_rollout_ref.rollout.gpu_memory_utilization=0.6
critic.model.use_remove_padding=True  critic.model.enable_gradient_checkpointing=True

要点：① 全角色开动态 batch，token 预算 24576 ≈ 8×(1024+2048)；② actor/critic 不 offload、ref offload； ③ rollout util 0.6——训练侧留 40% 给权重+优化器。

3.2 Megatron 版（ppo_trainer/run_qwen3_8b_megatron.sh）

actor_rollout_ref.actor.megatron.tensor_model_parallel_size=2   # ACTOR_TP
actor_rollout_ref.actor.megatron.pipeline_model_parallel_size=2   # ACTOR_PP
actor_rollout_ref.ref.megatron.tensor_model_parallel_size=2       # 与 actor 对齐
actor_rollout_ref.ref.megatron.pipeline_model_parallel_size=2
critic.megatron.tensor_model_parallel_size=2                      # critic 独立配置
actor_rollout_ref.rollout.tensor_model_parallel_size=2

要点：8 卡 = TP2×PP2×DP2；同一份 8 卡上 FSDP 版更简单，Megatron 版适合后续平滑扩到更大模型。

4. 30B-A3B MoE：单机 8 卡 GRPO（FSDP + 全 offload）

来源：run_qwen3_30b_a3b_fsdp.sh。单机塞 MoE 的典型做法——offload 全开：

data.max_response_length=4096        # 长思维链
actor_rollout_ref.actor.ppo_max_token_len_per_gpu=32768
actor_rollout_ref.actor.fsdp_config.param_offload=True
actor_rollout_ref.actor.fsdp_config.optimizer_offload=True
actor_rollout_ref.ref.fsdp_config.param_offload=True

要点：① 30B 总参数虽大但激活仅 3B，FSDP 分片 + 全 offload 后单机可训； ② token 预算 32768 > 8B 版（prompt 短、response 长）； ③ offload 换来的空闲显存可让 rollout.gpu_memory_utilization 上调。

5. 32B 稠密：双机 16 卡 GRPO（FSDP）

来源：run_qwen2_5_32b_fsdp.sh。稠密中模型跨机仍可用 FSDP：

trainer.nnodes=2
data.train_batch_size=1024       data.max_response_length=1024
actor_rollout_ref.rollout.tensor_model_parallel_size=8     # ROLLOUT_TP
actor_rollout_ref.actor.fsdp_config.param_offload=False
actor_rollout_ref.actor.fsdp_config.optimizer_offload=False

要点：① 32B×16bytes ≈ 512GB 静态，16 卡全分片每卡 32GB，仍有余量所以不开 offload； ② rollout TP=8（单 KV 判据：80G×util×8 ≫ 2×32B）；③ 跨机 all-gather 是瓶颈时可改 fsdp_size=8（Hybrid Shard，见并行篇 §3）。

6. 235B-A22B MoE：8 机 64 卡 GRPO（Megatron）

来源：run_qwen3_235b_a22b_megatron.sh（对应官方 DAPO 最佳实践文档）：

trainer.nnodes=8                                    # 64 GPU
data.train_batch_size=128        ppo_mini_batch_size=128   # DAPO 不重用数据
ACTOR_TP=4   ACTOR_PP=8   ACTOR_EP=4                      # 64 = 4×8×(EP4×DP2)
ALL_OFFLOAD=True                                            # param+optimizer 全 offload
+...megatron.override_transformer_config.recompute_method=uniform
+...megatron.override_transformer_config.recompute_granularity=full
+...megatron.override_transformer_config.recompute_num_layers=1
actor_rollout_ref.actor.ppo_micro_batch_size_per_gpu=1      # 固定 micro batch（超大模型）
actor_rollout_ref.ref.log_prob_micro_batch_size_per_gpu=4   # 前向 4×
actor_rollout_ref.rollout.tensor_model_parallel_size=8      # ROLLOUT_TP
actor_rollout_ref.rollout.expert_parallel_size=64           # ROLLOUT_EP
actor_rollout_ref.rollout.gpu_memory_utilization=0.75

要点：① MoE 显存大头是专家权重 → EP=4（训练）+ rollout EP=64（每卡一个专家分片）； ② full recompute + num_layers=1 = 逐层重计算，最省激活；③ micro batch=1 说明 235B 下激活才是瓶颈， 靠吞吐靠大 batch 攒；④ util 0.75 依赖训练侧全 offload。

7. 671B MoE：12 机 96 卡 GRPO（Megatron）

来源：run_deepseek_v3_671b_megatron.sh：

trainer.nnodes=12                                   # 96 GPU
ACTOR_TP=8   ACTOR_PP=12   ACTOR_EP=8   ACTOR_CP=1   # 96 = 8×12×(EP8 内含 DP)
OFFLOAD=True  OPTIM_OFFLOAD=True
+...optim.override_optimizer_config.optimizer_cpu_offload=True   # 混合 CPU 优化器
+...megatron.override_transformer_config.recompute_method=uniform
+...megatron.override_transformer_config.recompute_granularity=full
actor_rollout_ref.rollout.tensor_model_parallel_size=32          # ROLLOUT_TP
actor_rollout_ref.rollout.gpu_memory_utilization=0.6

要点：① 671B 静态 ≈ 10.7TB，即使 96 卡全 offload 后仍紧张——util 只有 0.6； ② rollout TP=32：671B 权重需 TP≥34 才装得下（80G×0.6×32=1.5TB ≈ 2×671B bf16），所以选 32； ③ optimizer_cpu_offload+分层 offload 是这个量级的必要手段。

8. 迁移到自己的模型/集群

  1. 找最近邻脚本：同架构（dense/MoE）+ 参数量最接近的官方脚本作为起点
  2. 先算静态显存：16×参数量 bytes，对照显存篇 §2 公式 决定分片度与 offload 级别；MoE 优先 EP，dense 优先 TP/分片
  3. rollout TP 用 KV 判据：单卡显存×util×TP > 2×参数量 取最小满足值
  4. token 预算按长度重算：ppo_max_token_len_per_gpu ≈ 数×(prompt+response)，从官方同长度脚本抄比例
  5. 验证整除约束：TP×PP×CP×EP(DP) = 总卡数；transformer 层数 ÷ PP 整除
  6. 跑 10 步试运行：trainer.total_training_steps=10 + disable_log_stats=False， 看峰值显存与各阶段耗时，再按性能篇 checklist逐项收紧
  7. 不覆盖、可复现：改环境变量而非改脚本；记录 pip freeze 与完整 hydra 命令行
